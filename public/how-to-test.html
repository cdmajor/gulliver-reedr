Test the extension on your computer

If the Chrome Web Store listing is still in review, it won’t show an install button yet. Use Load unpacked below — that’s the normal way to test while waiting on the store.

Fastest path (about 1 minute)

  1. On your computer, open this project folder in Terminal.
  2. Run: npm run prepare:unpacked
  3. That creates a folder named reedr-unpacked with the API already configured.
  4. Open Chrome and go to chrome://extensions
  5. Turn Developer mode ON (top-right toggle).
  6. Click Load unpacked.
  7. Select the reedr-unpacked folder (the folder itself, not a file inside it).
  8. Open any news/article page. Click the purple R bottom-right and ask a question.

Edge: use edge://extensions. Brave: brave://extensions.

No npm? Use the zip you already have

  1. Find public/reedr-extension-cws.zip in this repo (or download it from your site/GitHub).
  2. Extract it. You should see manifest.json directly in the extracted folder.
  3. Chrome → chrome://extensions → Developer mode ON → Load unpacked.
  4. Select that extracted folder.

Common mistakes

  1. Opening files from the zip — that only shows source code. You must use Load unpacked.
  2. Selecting the wrong folder — the folder you pick must contain manifest.json.
  3. “Reedr is not configured” — run npm run prepare:unpacked again, or open Reedr Settings and set API URL to https://gulliversoftwaretech.com/api, then Test → Save.
  4. No purple R — reload the webpage after installing. Some pages (Chrome Web Store, chrome:// pages) block extensions.

If you want to test the Chrome Web Store submission

  1. Open the Chrome Web Store Developer Dashboard.
  2. Open your Reedr item.
  3. If status is Pending review, public install isn’t available yet — use Load unpacked above.
  4. If you set visibility to Trusted testers, add your Google account under testers, then open the listing link while signed into that account and click Add to Chrome.
  5. After it’s Published, anyone can install from the listing URL (no Developer mode).

How you know it’s working

  1. Purple R appears on a normal webpage.
  2. Ask: “Summarize this in 3 bullets.”
  3. You get a reply about that page — success.
